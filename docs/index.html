در کمتر از یک دقیقه

کروم، اج، بریو

  1. فایل zip نسخهٔ کروم را دانلود و از حالت فشرده خارج کنید.
  2. به chrome://extensions بروید و Developer mode را روشن کنید.
  3. Load unpacked را بزنید و پوشهٔ استخراج‌شده را انتخاب کنید.
دانلود نسخهٔ کروم

فایرفاکس

  1. فایل zip نسخهٔ فایرفاکس را دانلود کنید (نیازی به استخراج نیست).
  2. به about:debugging ← This Firefox بروید.
  3. Load Temporary Add-on را بزنید و همان فایل zip را انتخاب کنید.
دانلود نسخهٔ فایرفاکس
